# 旧住所フィルター

Excelファイルの住所列をブラウザ上でチェックし、旧住所の可能性がある行をフラグします。

🔗 **[今すぐ使う → GitHub Pages URL]**

## 特徴

- **インストール不要** — ブラウザで開くだけ
- **プライバシー安全** — ファイルはサーバーに送信されません（ブラウザ内のみで処理）
- **全国対応** — 全47都道府県の平成大合併・消滅地名をカバー
- **無料** — 完全無料

## 判定ロジック

| # | パターン | 例 |
|---|---------|---|
| 1 | 消滅した郡名 | 橘樹郡、石城郡、南魚沼郡 など |
| 2 | 平成大合併で消滅した市町村名 | 津久井町、浦和市、具志川市 など |
| 3 | 旧字体 | 國、縣、區、濱、澤 など |
| 4 | 漢数字番地 | 三番地、十二番 など |
| 5 | カタカナ「ノ」区切り | 1ノ2、3ノ14 など |

## 使い方

1. ページを開く
2. Excelファイル（.xlsx / .xls）またはCSVをドラッグ&ドロップ
3. 住所が入っている列を選択
4. 「判定を実行」をクリック
5. 結果を確認し、「判定済みファイルをダウンロード」

## ファイル構成

```

```
