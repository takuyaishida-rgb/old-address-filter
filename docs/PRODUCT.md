# 郵便番号・旧住所フィルター — プロダクト定義

最終更新: 2026-07-30

## 1. これは何か

住所リスト（Excel／CSV）を投入すると、**郵便番号を付与し、旧住所・表記の異常をフラグして返す**ブラウザ完結型のツール。
ファイルはサーバーに送信せず、すべてブラウザ内で処理する。

公開URL: https://takuyaishida-rgb.github.io/old-address-filter/
GitHub Pages（公開リポジトリ）で配信しており、**URLを知っていれば社外の誰でも閲覧・利用できる**。

## 2. 解く問題

| 現場の問題 | 従来のやり方 | 本ツール |
|---|---|---|
| 送付先リストに郵便番号がない | 日本郵政サイトで1件ずつ検索 | 住所列から一括付与 |
| 郵便番号と住所が食い違う | 目視 | マスター突合でフラグ |
| 相続・古い謄本由来の住所が現行と違う | 気づけない | 消滅市郡・旧字体・漢数字番地を検出 |
| 同一物件が表記ゆれで重複 | 手作業 | 正規化キーで重複グループ化 |

想定ユーザー: 自社営業・データ作成チーム、および取引先（URLを渡して自走してもらう）。

## 3. 機能定義（2系統 + 拡張）

### A. 郵便番号（Postal）
- **A-1 付与**: 住所列から郵便番号を推定して列追加。`都道府県 → 市区町村 → 町域` の最長一致
- **A-2 突合**: 既存の郵便番号列とマスターを突合し、不一致・存在しない番号をフラグ
- **A-3 未確定の扱い**: 町域まで特定できない場合は**市区町村代表番号で埋めない**。空欄＋理由（`町域を特定できず` / `住所が不十分`）を返す

### B. 旧住所（Legacy）
- **B-1 検出**: 消滅郡名・消滅市名・消滅区名（東京35区）・消滅地名・旧字体・漢数字番地・カタカナ「ノ」区切り
- **B-2 現行住所の推定**: 旧市町村マップ（約2,500件）で現行住所を別列に追記（元の住所列は上書きしない）

### C. 拡張（オプション）
- **C-1 緯度経度・地図URL** の付与
- **C-2 重複検出**: 表記ゆれ正規化キーで同一物件をグループ化

## 4. 出力仕様

元の列は一切変更せず、右端に追記する。

| 列 | 条件 |
|---|---|
| 郵便番号（推定） / 推定レベル / 未確定理由 | A-1 ON |
| 郵便番号突合結果 | A-2 ON（既存郵便番号列あり） |
| 旧住所フラグ / 判定理由 | B-1 ON |
| 現行住所（推定） | B-2 ON |
| 緯度 / 経度 / 地理レベル / マップURL | C-1 ON |
| 正規化住所 / 重複ステータス / 重複グループID | C-2 ON |

## 5. 原則

1. **推定と事実を混ぜない** — 推定列は列名に「（推定）」を入れ、確度（町域／市区町村／不明）を必ず併記する
2. **黙って埋めない** — 確度が落ちる代替値で穴埋めせず、空欄＋理由で返す
3. **元データを壊さない** — 上書き・並び替え・行削除をしない。追記のみ
4. **ブラウザ内処理** — アップロードなし。取引先に渡せる前提を崩さない
5. **絵文字を使わない** — UI・出力ともアイコンはSVG、ラベルは日本語テキスト

## 6. データソース

| データ | 出所 | 件数 |
|---|---|---|
| 郵便番号マスター | 日本郵便 ken_all | 約12万 |
| 旧市町村マップ | NAreaCode（MIT）＋ ken_all | 約2,500 |
| 地理データ | geolonia 住所データ | 約12MB |

## 7. スコープ外

- 番地レベルのジオコーディング（町域重心まで）
- 建物名・部屋番号の正規化（住所本体と分離するのみ）
- 住民票・登記の名寄せ、氏名の異体字判定（別ツール）
