# デザインシステム — 郵便番号・旧住所フィルター

最終更新: 2026-07-30
方針: Notion風・モダン・静かなUI。**絵文字は一切使わない**。装飾より情報の階層で語る。

## 1. 原則

1. フラットに保つ — 影を使わない。面の区別は1pxのヘアラインと極薄の背景差で行う
2. アクセントは1色 — 青のみ。赤・黄・緑は「状態」を示すときだけ使い、装飾に使わない
3. 数字を主役にする — 結果は等幅数字（tabular-nums）で大きく、ラベルは小さく
4. アイコンはインラインSVG（16px / stroke 1.5 / currentColor）。絵文字・記号文字（⬆ 等）は使わない
5. 文言は体言止めの日本語。感嘆符を使わない。「〜しました」より「完了」

## 2. カラートークン

```
--ink            #37352F   本文
--ink-64         rgba(55,53,47,.64)   副文
--ink-48         rgba(55,53,47,.48)   補助・プレースホルダ
--ink-16         rgba(55,53,47,.16)   入力枠線
--ink-09         rgba(55,53,47,.09)   面の境界
--ink-04         rgba(55,53,47,.04)   ホバー面
--canvas         #FFFFFF   カード面
--canvas-soft    #F7F7F5   ページ地
--accent         #2383E2   主アクション・フォーカス
--accent-ink     #0B6BBF   ホバー
--accent-soft    #E7F3F8   選択中の面
--flag           #E03E3E   旧住所・不一致（要対応）
--flag-soft      #FDEBEC
--warn           #CB912F   未確定（判断保留）
--warn-soft      #FAF3E8
--ok             #448361   問題なし
--ok-soft        #EDF3EC
```

状態色の使い分けは1対1で固定する。赤=要対応 / 黄=未確定 / 緑=問題なし。

## 3. タイポグラフィ

UIはサンセリフのみ（セリフ見出しは使わない）。

```
font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI",
             "Hiragino Kaku Gothic ProN", "Yu Gothic", Meiryo, sans-serif;
```

| 用途 | サイズ / 太さ / 字間 |
|---|---|
| ページタイトル | 32px / 700 / -0.02em |
| リード文 | 15px / 400 / --ink-64 |
| セクション見出し | 15px / 600 |
| セクション番号 | 11px / 600 / 0.08em / --ink-48 / 大文字 |
| 本文・入力 | 14px / 400 |
| 補助・注記 | 12px / --ink-48 / line-height 1.6 |
| 統計の数値 | 30px / 600 / tabular-nums |
| テーブル見出し | 12px / 500 / 0.04em / --ink-64 |

行間は本文1.55、注記1.6。

## 4. スペーシング・形状

- 基準4px。使う値は 4 / 8 / 12 / 16 / 24 / 32 / 48 / 72
- 角丸: 入力・ボタン 4px、カード 8px、バッジ 3px
- 境界線は必ず1px。太線・二重線は使わない
- コンテンツ幅 760px、左右パディング24px、上72px / 下96px

## 5. コンポーネント

| 部品 | 仕様 |
|---|---|
| カード | `--canvas` + 1px `--ink-09` + radius 8 + padding 28/32 |
| セクション見出し | `01` 形式の番号（--ink-48）+ 見出し。ステップ番号に丸背景を付けない |
| モードセレクタ | 横並びのセグメント。選択中は `--accent-soft` 面 + `--accent-ink` 文字 + 1px accent枠 |
| ドロップゾーン | 1px破線 `--ink-16` + `--canvas-soft`。hover/dragoverで accent枠 + accent-soft面。中央にSVGのアップロードアイコン |
| セレクト・テキスト入力 | 高さ36px相当（padding 9/12）、focusで accent枠 + 3pxリング rgba(35,131,226,.15) |
| チェックボックス | 16px、カスタム描画。選択時 accent塗り + 白いチェック |
| 主ボタン | accent塗り・白文字・全幅。disabledは `--ink-16` 面 / `--ink-48` 文字 |
| 副ボタン | 白面 + 1px `--ink-16`。hoverで `--ink-04` |
| 統計タイル | `--canvas-soft` 面 + 1px `--ink-09`。数値の色で状態を示す（赤/黄/緑） |
| バッジ | `旧住所` = flag-soft/flag、`未確定` = warn-soft/warn、`一致` = ok-soft/ok |
| テーブル | 罫線は行下1pxのみ。縦罫線・ゼブラを使わない。見出しは背景なし |
| 注記 | カード下部に12pxで置く。警告記号は使わず「未確定」等の語で示す |

## 6. 画面構成（IA）

単一カラム・上から下の3ステップ。左サイドバーやタブは持たない。

```
郵便番号・旧住所フィルター
リード文（何をするか / ブラウザ内処理である旨）

01  ファイル
    ドロップゾーン → 選択中のファイル名

02  処理内容
    モードセレクタ:  郵便番号を付ける | 旧住所を判定する | 両方
    住所列（必須）
    郵便番号列（任意・突合に使用）
    詳細オプション（折りたたみ）
      現行住所（推定）を追記 / 緯度経度・地図URL / 重複検出
    注記（読み込むマスターと初回の待ち時間、元の列は変更しない旨）
    [ 実行 ]

03  結果
    統計タイル: 総件数 | 要対応 | 未確定 | 問題なし
    [ 判定済みファイルをダウンロード ]（副ボタン）
    リスト（最大50件表示）: # / 住所 / 判定 / 理由
```

- 実行前は 03 を出さない。02 はファイル選択後に出す
- モードによって 02 の項目を出し入れする（郵便番号のみなら旧住所オプションを隠す）

## 7. 状態表現

| 状態 | 表示 |
|---|---|
| 読込中（マスター） | 実行ボタンをdisabled、直下に12pxで「郵便番号マスターを読み込み中（初回のみ）」 |
| 処理中 | 「判定中」＋件数の進捗。スピナーは使わず文字で示す |
| 完了 | 統計タイルとリストを表示。トーストは出さない |
| エラー | 実行ボタン直下に赤文字1行＋対処（例: ローカルファイル起動では動作しないため公開URLで実行する） |
| 該当0件 | リストの代わりに「要対応の行はありません」を --ink-48 で中央に置く |

## 8. 禁止事項

- 絵文字、記号文字による装飾（⚠ ✅ ⬆ 等）
- 影・グラデーション・角丸16px以上の大きな丸み
- アクセント以外の彩色（状態色を除く）
- 3色を超える同時使用（ink系＋accent＋状態色1つまで）
- 「！」を含む文言、擬人化された語りかけ
